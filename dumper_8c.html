DataVector * JoinDump ( const DataVector *  v1,
const DataVector *  v2 
)

Merges two DataVectors, combining records with same id.

For records with matching id:

  • count and cost are summed.
  • primary = logical AND (1 only if both are 1).
  • mode = maximum of the two.

The resulting vector is sorted by cost (ascending) after merge.

Parameters
v1First DataVector.
v2Second DataVector.
Returns
New DataVector containing the merged result, or NULL on error.
